## Goal and approaches

Implement a genuinely usable read-only Figma REST capture component and a project-controller import operation. It reads explicitly selected basic node IDs from one Figma file/version, validates the actual bounded API response, requires separately supplied human acceptance criteria, and publishes an exact traceable source through the existing project service. Tests use an in-memory HTTP handler and synthetic token/data only. No real credentials/file are supplied, so no live Figma call is executed. There is no new UI or fake future panel in this increment; native connection/review UX follows only after this backend is verified. Existing normalized local import/virtual execution remain unchanged.

Considered: wrapping Figma desktop/embedding a browser (violates native same-window goal); fetching whole files/images and inferring business acceptance (excess data, unsupported semantic claim); selected-node REST capture with explicit criteria (chosen, bounded and traceable). Existing sync ITestSourceProvider.Parse remains appropriate for local bytes, not remote authority; the asynchronous reader is private to the first-party domain assembly. No SDK/host ABI or schema version change is needed.

OpenAI-dependent implementation remains blocked by a separate credential decision: no usable key is present and the credential skill requires an explicit choice before that code. No key creation, credential reading, API examples or API client implementation belongs to this plan. Provider-neutral requirements and computer execution boundaries below are conceptual design, not a claimed AI client.

## Exact Figma component contract

Namespace Workbench.Testing.Domain.Sources.Figma. Add FigmaReadRequest(string FileKey,IReadOnlyList<string> NodeIds,string? Version=null); file key is ASCII alphanumeric 1..128, node IDs are basic decimal:decimal strings 1..64 (1..16 unique ordinal IDs), optional version is nonempty valid Unicode 1..64 without controls/whitespace and is URL-escaped. Complex instance node IDs/URLs are explicitly unsupported at this stage. Capture caller lists before first await and never enumerate arbitrary input again.

FigmaFileReader(HttpMessageHandler? handler=null).ReadAsync(FigmaReadRequest request,Func<CancellationToken,Task<string?>> getToken,CancellationToken cancellationToken=default) returns FigmaCapture. One GET only to https://api.figma.com/v1/files/{escaped key}/nodes?ids={escaped comma-joined captured IDs}&depth=2 plus escaped version when supplied. No arbitrary base URL, file discovery, images, link traversal, comments, writes, Webhooks, automatic retries or polling. Default per-call HttpClientHandler disables redirects, cookies and default credentials; no default auth header. An explicitly injected handler is caller-owned test transport, never a security sandbox. Default transport/client/response are disposed after actual work settles. Per-request token is X-Figma-Token; token callback result is never put in records, query, error text or logs. Missing/invalid credentials (only ASCII visible nonwhitespace1..4096 characters, no CRLF) refuse before HTTP. Never evaluate the credential callback on invalid request.

Use ResponseHeadersRead and a streaming 1 MiB + one-byte over-limit detector; reject oversized Content-Length before body read, unsupported Content-Encoding, malformed/non-UTF8 JSON and oversized bodies even without Content-Length. Accept application/json (optional UTF8 charset), reject non-JSON media types. One cooperative 30-second linked deadline includes credential/read work. Cancellation requests are not proof that ignored-cancellation work stopped: await actual callbacks/transport/read; no WaitAsync timeout wrapper or abandoned task. Caller cancellation propagates sanitized OperationCanceledException; deadline maps to safe Timeout only after actual settlement. Do not persist error response bodies or request/response object strings. Fixed FigmaReadError enum: InvalidRequest, CredentialsUnavailable, AuthenticationRefused, NotFound, RateLimited, Unavailable, ResponseTooLarge, ResponseInvalid, Timeout. FigmaReadException contains only the enum and optional RetryAfterSeconds (integer 0..86400 from 429); safe fixed Message, no inner exception. Map 401/403,404,429,other/non-success/redirect, transport errors explicitly; no automatic retry, Upgrade-Link rendering or raw server/error details.

FigmaCapture preserves exact OriginalJson bytes, actual file Name and Version, captured request, and selected FigmaNodeCapture(Id,Name,Type,Characters). Its public collections/bytes are defensive copies/read-only views; credentials never enter its shape. Parse JSON at max depth32, reject duplicate properties at any object level and invalid Unicode/escaped surrogates, permit bounded unknown API fields as data (Figma evolves). Required root name1..200/version1..64/nodes object; every requested key must exist and be non-null, no extra nodes-map keys; each document.id must match its requested key, name1..200/type1..64, optional characters0..4096. Preserve full raw response and input order; never truncate or silently omit unavailable nodes. Explicit requested version must equal actual response version. No semantic actions, external URLs or business criteria are inferred from any document text.

FigmaSourceBuilder.CreateDraft(FigmaCapture capture,IReadOnlyDictionary<string,IReadOnlyList<string>> acceptanceCriteria) -> TestSourceDraft. Require exact same ordinal node keys and 1..16 nonblank valid-Unicode criteria per node, each<=4096, at most200 criteria TOTAL across the request; capture defensive copies, refuse extras/missing/duplicates/oversize before any publication. Return Kind Figma, ProviderId figma.rest.nodes.manual-criteria, ProviderVersion 1, DocumentId fileKey@actualVersion (<=200), file Name as Title, exact raw OriginalJson, one item per requested node (Locator actual nodeID, Title actual node name, Description includes observed type/characters within4096 or refuses, criteria exactly caller-supplied, VirtualScenario=null). Thus all generated cases remain manual. Source revision covers raw API bytes plus the explicitly supplied criteria; never claim Figma returned business acceptance criteria. A response with no user criteria cannot become an executable test or a fabricated source.

Internal CaptureRequest/CaptureCriteria helpers are shared between reader/builder/controller so synchronous capture and caps have one definition. Invalid inputs (including count/field/aggregate200 caps) use FigmaReadException.InvalidRequest; HTTP body byte overflow uses ResponseTooLarge. Refuse201 criteria before credential/HTTP/publication. Existing combined multi-source generator200 and Core4MiB encoded-envelope caps remain authoritative: a legal raw/input-sized draft may still fail StoreLimitExceeded at Core publication; do not duplicate its serializer, increase caps or truncate. Synthetic tests cover200 success/201 refusal and safe final envelope refusal. No generic provider registry/new SDK capability placeholder.

## Controller operation and ownership

Preserve existing TestingController(context,adapter=null) constructor signature. Add overload TestingController(context,adapter,FigmaFileReader reader) for injected test composition; default constructor uses a default reader. Add ImportFigmaAsync(FigmaReadRequest request,IReadOnlyDictionary<string,IReadOnlyList<string>> acceptanceCriteria,Func<CancellationToken,Task<string?>> getToken,CancellationToken cancellationToken=default) -> Task<TestSourceSnapshot>. Admit actual operation BEFORE input enumeration/callback prefixes, capture request/criteria under existing AdmitCaptured, serialize with actual authoring work, await the real reader, build draft, publish through captured _testing facade, then update the local source summary from the genuinely acknowledged returned snapshot, with no fallible ListSources or other IO after publication acknowledgment. Complete reread remains an explicit Refresh operation. Linked caller/context-lifetime cancellation, actual operation retention and existing before-leave/Stop drain apply. It does not register/read a new secret automatically, start background work, publish after closed authority, or add a UI/settings/credential placeholder. The future native entry supplies its explicitly registered secret callback; this code does not touch real secrets.

Sanitize FigmaReadException at controller boundary to existing PluginTestingException codes, INSIDE the admitted synchronous capture delegate as well as the asynchronous reader/builder body (AdmitCaptured otherwise erases non-SDK exceptions): InvalidRequest/ResponseInvalid -> InvalidTestSource; ResponseTooLarge -> StoreLimitExceeded; remaining safe remote failures -> TestingFailed. No new SDK/store error allow-list or raw provider detail. Existing dirty draft/old source bytes are never destructively changed by capture/HTTP/parse/criteria/store failures; before publication admission no new record is written. This is not a cross-call rollback/transaction claim. Immediately after remote read and before publication, check linked cancellation and admit publication atomically under the same _sync close barrier: Stop winning first refuses publication; a publication ticket admitted first remains part of the already-owned operation and Stop drains it until actual settlement, even if store admission/commit occurs later. Release the lock before invoking any service/callback prefix. Core facade Close remains the final host-context admission barrier. Acknowledged committed source is returned and summarized even if cancellation/Stop arrives afterward; no post-commit cancellation check or fallible list refresh may relabel it as uncommitted failure. If a store call itself fails around its commit point, retain any actual bytes, do not infer absence, delete or automatically retry. No fake empty response or success. Before-leave may wait for the admitted request's actual settlement within cooperative deadline; no promise of forced cancellation. Closed admission must not enumerate request/criteria or invoke token/HTTP. A held ignored-cancellation transport must keep preparation/Stop and roots pending until actually released; no early cleanup/root release.

## Controlled-computer design: implementation still pending

The existing service accepts only virtual.task-form.v1 and fixed SIMULATED BMP. Real desktop control CANNOT be enabled by swapping an adapter or changing an IsSimulated flag. A later separate increment must add explicit versioned target/run/evidence contracts and migration/read compatibility, leaving old schema1 records and old plugin ABI intact.

Recommended first real target is a new isolated owned synthetic Windows fixture process on the CI desktop, never another user's desktop session. Bind a grant to project/plugin/device/session, exact process PID+start time+canonical binary SHA+window handle/root and bounded typed actions/selectors. Validate before every action/capture; PID reuse, window replacement, elevation, session change, unknown selectors, expired/revoked grants and arbitrary executable/URL/shell/coordinates refuse. No global desktop search/keyboard injection, screen scraping or credential fields by default. User-selected external targets require explicit target/data/action approval; no inferred permission from plugin trust. Trusted in-process code/ALC remain unsandboxed.

UIA driver belongs in a separate Windows-only process with an explicit protocol and actual process retirement. A cooperative cancellation response is not process termination; retain session ownership/lease until actual delegate/driver exit, including ignored cancellation. StepStarted must be durably anchored before actual device action, then actual observed text and target-window-only screenshot evidence before StepFinished. A blocked action, lost driver, partial screenshot or uncertain completion remains failed/interrupted, not success. Retry is a new linked frozen run from step1; no undo/exactly-once/checkpoint-resume guarantee. Captures need explicit policy and a new non-simulated bounded format, with original bytes/hash/target identity/observed timestamps and redaction policy; do not relabel current simulated frames as real screenshots. Full-desktop capture is not authorized. UI pages must remain host WinUI contributions, not embedded target/driver windows.

This increment writes this design only for real computer execution. No OS control API, target grant, real screenshot, arbitrary-agent loop or UIA runtime is implemented/claimed. Actual AI/Figma credential-backed integration, new native Figma UX, Windows11 human/IME/DPI/picker/accessibility and real-device acceptance remain explicit later gates.
