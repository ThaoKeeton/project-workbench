# Native source and virtual activity coordination

This bounded source step implements an independent part of the owned-pilot Task4 requirements while GitHub explicitly blocks current CI startup for account payment/spending-limit reasons. It does not repair or qualify the historical9/27 native abort, create the owned execution panel, or change any Windows/release acceptance gate. The user asked continuous autonomous work and deferred human acceptance; the following engineering choices are the controller's, without another ordinary confirmation.

Current callback ownership retains work but does not serialize it; remote admission excludes only another remote operation. Queue/Run/Retry/StartQueued return before actual virtual supervisor retirement. A committed terminal journal may still own that supervisor. Source requests and virtual transitions therefore need one plugin-private reservation across all existing page/command paths.

Approaches considered: a mutex around NativeActionOwner would also block Cancel/history and would still confuse start with completion; waiting unconditionally for the virtual run would silently queue a source request behind live work; a fail-fast transition reservation plus an actual terminal-only retirement join preserves current virtual semantics. Choose the last. Local/remote imports, rule generation, Run/queue/start/retry use it; ordinary cancellation, history/evidence, refresh/export and accepted draft/form edits retain their existing separate channels.

Host minimum0.4.0, SDK/API1, Testing0.2.0, immutable Core/owned formats and public SDK remain unchanged. Coordinator state is per plugin instance/project, not global. Competing starts fail before capture/backend work; no queued automatic action, generic execution engine, arbitrary device operation, runtime mode or provider flag. In-process code remains trusted, without a sandbox claim.

Add internal Domain `Task<bool> TryJoinPriorTerminalRunAsync()` retained as a non-serialized operation. A live/queued/cancel-requested owned attempt returns false without cancellation/journal/error/selection changes. A terminal attempt joins the existing actual RunWork/shared RetirementWork and succeeds only with proven release. Use actual current ownership, never selected history. Existing `JoinRunWorkAsync`/`RetireAttemptAsync` remain the only retirement algorithm. Grant friend access only to Workbench.Testing; no SDK/Core contract expansion.

The private coordinator retains its completion before the synchronous prefix, calls no delegate under its lock, rejects busy/closed admission, and has counted Seal/permanent Terminal/actual Drain. Its ordinary Source route reserves, synchronously captures/copies input, joins only terminal virtual retirement, then invokes the source action. Virtual transitions share the reservation and retain RecordOwned/final refresh while preserving existing queued-start semantics. Actual reservation remains held through final informational idle notification even if presentation IsBusy=false there.

RemoteSource reserves first and immediately installs the existing NativeRemoteOperation CTS before synchronous capture or retirement waiting. It owns the entire existing remote task, cancellation callbacks/settlement and extra final page notification. Cancellation during handoff marks that token, continues joining actual uncancellable retirement, then forbids credentials/provider IO. Check the token after an initial awaited notification too. No second CTS/controller, abandoned wait, self-drain, duplicate Stop or fabricated idle.

A private tagged admission refusal maps only Busy/Closed to existing StoreBusy/TestingContextClosed. Capture/backend errors with the same SDK code remain actual operation errors; no global IsBusy inference. SourcePanel supplies synchronous capture callbacks, deep-copied before any async handoff, and does not use a catch-all that can overwrite another source operation's status. Commands unwrap the private tag into the SDK exception; page errors render its safe code. Accepted backend/capture failures retain existing source settlement behavior. Presentation failure never changes committed run/receipt/case outcomes or triggers a request/retry, and never replaces the original action failure.

Leave seals coordinator/owner/remote before cancellation and retains their actual work plus existing Domain preparation/dispatcher tails until reopening. Stop/lifetime close all admission permanently. Same-project page unload keeps its existing detach-only semantics. The coordinator does not replace owner-wide notification/picker/decoder ownership, and never self-drains an owner callback. All fields must remain safe through initialization failure and Stop; the public parameterless plugin activation path stays intact.

All existing entry points in the frozen reconnaissance map must route through this reservation.
