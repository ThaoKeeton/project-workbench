# Traceable Testing Plugin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Install a real native testing plugin that turns explicit local snapshots into editable traceable cases, actual CSV, and durable virtual-target run/evidence/cancel/retry records.

**Architecture:** Add optional testing services to the unchanged plugin ABI, backed by a project-root guarded store and a revoked/drained context facade. A portable domain assembly implements real parsers/generation/export/virtual execution; a separately packaged WinUI entry renders directly in the host. All execution in this stage uses the named in-memory target.

**Tech Stack:** C#/.NET10.0.403, WinUI3/Windows App SDK1.8.260921001, existing System.Text.Json and xUnit; no new network/AI/device dependencies.

**Spec:** `docs/superpowers/specs/2026-11-07-traceable-testing-design.md`

## Review Focus

- Caller mutation after an async call: capture arrays/lists/text authority before scheduling; return defensive snapshots so source/case/run receipts cannot be altered later (Tasks1/2/3).
- Old valid success adjacent to missing/divergent/future journal bytes: refuse the record and retain bytes, never fall back to an earlier passing projection (Task2).
- Close during initialization, blocked filesystem work, picker or cancellation: revoke fresh calls, retain actual work/root, and permit same-page correction after another participant's settled preparation failure (Tasks3/4/5).
- Typing a final instruction immediately before leave, failed autosave, mapping invalidation and CAS conflict: preserve exact last buffer and refuse automatic run until durable mapped cases are valid (Tasks4/5).
- UTF8 BOM/Unicode/newline/formula-leading text and numeric-looking managed IDs: exact original-source/store identity, safe bounded native plain text and explicitly changed CSV text policy, not silent coercion or fabricated import/export (Tasks1/4/5).
